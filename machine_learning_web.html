01 / PENGERTIAN

Apa itu
Machine Learning?

Machine Learning merupakan salah satu bagian penting dari Artificial Intelligence yang memungkinkan komputer mempelajari pola dari data.

Machine Learning (ML) adalah bagian dari Artificial Intelligence (AI) yang memungkinkan komputer mempelajari pola dari data dan menggunakan pola tersebut untuk membuat prediksi atau keputusan terhadap data baru.

02 / PROCESS

Bagaimana
Machine Learning Bekerja?

Secara sederhana, sistem Machine Learning menggunakan data sebagai bahan pembelajaran untuk membangun sebuah model yang kemudian dapat digunakan pada data baru.

01 — INPUT

DATA

Kumpulan informasi yang digunakan sebagai bahan pembelajaran bagi komputer.

02 — LEARN

TRAINING

Algoritma mempelajari pola dan hubungan yang terdapat dalam data.

03 — MODEL

MODEL

Hasil pembelajaran yang dapat digunakan untuk memproses data baru.

04 — OUTPUT

PREDIKSI

Model menghasilkan prediksi atau keputusan berdasarkan pola yang telah dipelajari.

03 / TYPES

Jenis-Jenis
Machine Learning

Secara umum, pendekatan Machine Learning dapat dibagi menjadi tiga kategori utama.

01

Supervised Learning

Model belajar menggunakan data yang sudah memiliki jawaban atau label. Tujuannya adalah membuat model mampu memprediksi hasil yang benar pada data baru.

Contoh:
Mendeteksi email sebagai spam atau bukan spam.
02

Unsupervised Learning

Model bekerja dengan data yang tidak memiliki label dan berusaha menemukan pola, hubungan, atau kelompok yang terdapat di dalam data.

Contoh:
Mengelompokkan pelanggan berdasarkan kebiasaan belanja.
03

Reinforcement Learning

Sistem belajar melalui interaksi dengan lingkungan. Tindakan yang baik mendapatkan reward, sedangkan tindakan yang kurang baik dapat mendapatkan penalti.

Contoh:
AI belajar memainkan sebuah permainan melalui percobaan dan kesalahan.

06 / ANALYSIS

Manfaat & Kekurangan

✓ MANFAAT

  • Mengolah data dalam jumlah besar.
  • Membantu membuat prediksi.
  • Mengotomatisasi berbagai pekerjaan.
  • Menemukan pola dalam data.
  • Membantu pengambilan keputusan.

× KEKURANGAN

  • Membutuhkan data yang cukup dan berkualitas.
  • Hasil dapat dipengaruhi oleh kualitas data.
  • Model dapat menghasilkan bias.
  • Membutuhkan sumber daya komputasi.
  • Prediksi tidak selalu benar.
07 / CONCLUSION

Data → Learn → Predict

Machine Learning memungkinkan komputer belajar dari data, mengenali pola, kemudian menggunakan pola tersebut untuk membuat prediksi atau keputusan. Teknologi ini menjadi salah satu bagian penting dalam perkembangan Artificial Intelligence dan telah diterapkan dalam berbagai bidang.
